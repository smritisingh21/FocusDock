# FocusDock
 
Tech used : React , Javascript , HTML , CSS

A go-to web app for all your **productivity needs** in one place.
This is a basic-react app that contains various utilities like  : 
1. To-do list
2. Pomodoro
3. Sticky note
4. Reminder
5. Focus Music-streaming
6. personalized wallpaper and theme options
7. Screen-time calculator
